GeoScope プライバシーポリシー

最終更新: 2026年5月14日

GeoScope (以下「本サービス」) は、利用者のプライバシーを尊重し、個人情報の保護に努めます。本ポリシーは、本サービスが取り扱う情報の種類と利用方法を定めるものです。

2. 利用目的

  • 本サービスの認証および利用者識別
  • 探索ジョブの実行および結果の保存・表示
  • サービス改善のための統計分析 (個人を特定しない集計)
  • 不正利用検知・運営上必要なやり取り

3. RunPod API key の取り扱い

BYO (Bring Your Own) クラウドGPU 設計に基づき、利用者の RunPod API key は以下のように扱います。

  • ブラウザ localStorage に保存: 同じブラウザ・同じデバイスで本サービスを使う限り、利用者が明示的に消去するまで保存されます。
  • HTTP ヘッダで送信: 探索リクエスト時にのみ X-RunPod-Api-Key ヘッダで本サービスのサーバーに送信されます。
  • DB に永続化しない: サーバーはこのキーを Job レコードの一時フィールドに保存しますが、ジョブの完了・失敗・キャンセル時にデータベースから削除します。
  • ログにマスク: アクセスログ・エラーレポートでは末尾数文字以外をマスク (Sentry 等のエラー追跡サービスを利用する場合)。

4. 第三者提供

本サービスは、以下を除き、利用者の個人情報を第三者に提供しません。

  • 利用者の同意があった場合
  • 法令に基づく開示請求があった場合
  • RunPod (利用者自身のキーによる API 呼び出し) — 利用者の指示に基づく Pod 起動リクエストのみ
  • Cloudflare (CDN・R2): IP アドレスの一部が転送経路で経由

5. Cookie / セッション

  • 本サービスは認証セッションを JWT (JSON Web Token) ベースで管理します。JWT は localStorage に保存され、API リクエストの Authorization ヘッダで送信されます。
  • 本サービスはトラッキング目的の第三者 Cookie を使用しません。

6. データの保持期間

  • 利用者がアカウントを削除すると、関連するすべてのデータ (プロジェクト、アノテーション、ジョブ履歴、API key) は即座に削除されます。
  • サーバーアクセスログは原則として 30 日以内に削除します。
  • バックアップは最大 30 日保持され、その後完全に削除されます。

7. データ削除権

利用者は本サービスのアカウント設定画面の「アカウント削除」ボタンからいつでもアカウント削除を要求できます。削除は即時実行され、復旧はできません。

8. 外部サービス

本サービスは以下の外部サービスを利用しており、それぞれのプライバシーポリシーが適用されます。

  • Google (OAuth)
  • RunPod (利用者が自身のアカウントで利用)
  • Cloudflare (CDN, R2 ストレージ)

9. ポリシーの変更

本ポリシーは予告なく変更される場合があります。重要な変更がある場合は本サービス内で告知します。
