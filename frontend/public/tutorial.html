🔰 はじめてガイド

赤色立体地図 + AI で「あなたの目で気になった地形」を全国から探し出す、20分の入門ツアー。

🧐 GeoScope って何ができる?

日本全国の 地形を 5m メッシュの精度 で見て、人工地形 (古墳・城跡・古戦場・隠れ里・棚田・採掘跡など) を AI に学習させて自動で探す ツールです。

あなたがやることはシンプル:

  • 気になる場所を ⭕ や ❌ で印を付ける (アノテーション)
  • 「探索」ボタンを押す
  • AI があなたの ⭕ を真似て全国 100万タイルをスキャン
  • 怪しい地形を地図上にリスト化
✨ 1人の趣味で「全国の古墳候補を AI に探させる」が現実になっちゃう時代です。

1 まず地図を眺める

ログインしたら、まず 赤色立体地図 (RRIM) を有効にして近所を眺めてみましょう。サイドバー左の「🩻 赤色立体地図」のチェックを ON。

赤色立体地図ってなに?

標高データを「立体感」がくっきり見えるよう色付けした地図です。航空写真では木に隠れて見えない 微地形 (古墳の盛り土、城跡の堀、棚田の段差) が、影絵のように浮かび上がります。

💡 まずは奈良県 (橿原・桜井あたり) や 千葉県 (印旛沼周辺) を z=16 で眺めると、有名な古墳群がボコボコ見えて感動します。

2 プロジェクトを作る

「何を探したいか」をプロジェクトとして分けます。

  • 古墳プロジェクト: 円墳・前方後円墳など、ぽっこりした人工地形
  • 城跡プロジェクト: 山城の堀切・曲輪・土塁などの直線的な人工地形
  • ご当地プロジェクト: 例 「秩父の隠れ里」「茶畑の跡」など、何でもアリ

ヘッダ上部のプロジェクトセレクタ横の「+」ボタンで作成。名前は後で変えられます。

3 ⭕❌ で印を付ける (アノテーション)

地図上で対象を囲むように ドラッグして bounding box を描く → ⭕ (正例) または ❌ (負例) を選択。

クリックではなくドラッグなのは、AI が「どこからどこまでが対象か」を学習するためにサイズ情報も必要だから。古墳や城跡の輪郭くらいの大きさで囲むのが目安です。

コツ

  • ⭕ は 50〜100個 集めるところからスタート。少なすぎると AI が学習できません
  • ❌ も同じくらい 入れると賢くなる (「これは古墳に似てるけど違う」を教える)
  • 多少間違っていても OK。量 > 質 です
💡 ⭕❌❓ の使い分け、bbox の精度、ラベル運用などの詳細は ヘルプ「ベストプラクティス」 へ。

4 自分の GPU を繋ぐ (BYO RunPod)

探索は AI の学習 + 全国スキャンで RTX 4090 を 6〜8時間 使うので、運営の GPU ではなく あなた自身の RunPod アカウント で実行します。

セットアップ (1回だけ)

  1. 招待リンク から RunPod 登録 (非欧州ユーザーは登録ボーナス $0〜$10、多くは $5)
  2. RunPod 画面で API key を発行
  3. GeoScope の右上アバター → アカウント設定 → RunPod API Key 欄に貼って「検証」

料金 (探索モード別、RunPod に直接支払い)

  • 🐌 節約 (Community 4090): 約 500〜700円/scan、在庫切れ時は待ち
  • ⚖️ 標準 (Secure 4090、推奨): 約 800円/scan
  • ⚡ 急ぎ (Secure + 高性能 GPU): 800〜1500円/scan
  • 運営 (geoscope.jp) は手数料 0、紹介リワードだけ受け取り
💡 Pod は scan 完了後 idle 5分で自動削除。永続ストレージ無し設計なので アイドル料金 0 円。

5 「探索」ボタンを押す

サイドバーの「探索」を押すと、裏側で:

  1. あなたの RunPod Pod が起動 (~30秒〜2分)
  2. DEM データを R2 から取得
  3. あなたの ⭕❌ で YOLO26n を学習 (~10〜30分)
  4. 全国 100万タイルをスキャン (~6〜8時間)
  5. 怪しい地形を 「探索結果」ラベル 付きで地図に表示

WebSocket で進捗が流れてくるので、ブラウザ閉じても進みます。

💡 「精度モード」を選べます。厳選 (0.5): 数十件のみ高確度。推奨 (0.3): バランス型。網羅 (0.2): 数千件、後で絞り込む派向け。

6 結果を眺めて選別する

検出結果は ギャラリーモード 🖼 で一気に見られます (サイドバー右上)。

使える操作

  • 👍/👎 ボタン: 1件ずつ承認/却下
  • フィルタ: ラベル・都道府県・スコア閾値で絞り込み
  • 一括操作: 選別済みのアノテーションをまとめて削除・ラベル付け
  • 📥 エクスポート: GeoJSON / CSV で QGIS や Google My Maps にインポート可能
🏆 良かった検出に ⭕ を、明らかにダメな検出に ❌ を付けて再学習を回すと、モデルがどんどん賢くなる感覚は中毒性あり。
